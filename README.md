# projcat
# курсовой проект по серверной разработке - CatVerse 

Полноценный блог о кошках, разработанный на чистом PHP с применением собственного backend-фреймворка и архитектуры MVC.

## Технологии

- **PHP 8.1+** (нативный, без фреймворков)
- **MySQL** (база данных)
- **MVC-архитектура** (Models, Views, Controllers)
- **PDO** (подготовленные выражения для защиты от SQL-инъекций)
- **Сессии**, хеширование паролей, подготовленные запросы
- **CSS3** (чёрно-розовая тема, адаптивность, анимации)

## Функционал

### Публичная часть
- Каталог котов с фотографиями
- Поиск и фильтрация (по цвету, возрасту)
- Пагинация списка
- Статистика популярных кличек и пород
- Статьи блога с отображением автора
- Комментарии к котам

### Личный кабинет
- Регистрация и авторизация
- Добавление котов в каталог
- Редактирование своих статей
- Лайки и избранное
- Выход из аккаунта
